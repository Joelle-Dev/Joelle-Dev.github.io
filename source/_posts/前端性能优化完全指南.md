## 前言

前端性能优化是每个前端开发者必须掌握的技能。良好的性能不仅能提升用户体验，还能降低服务器成本、提高 SEO 排名。本文将从多个维度全面介绍前端性能优化的方法和实践。

## 一、性能优化指标

### 1.1 核心 Web 指标（Core Web Vitals）

Google 提出的三个关键指标：

- **LCP (Largest Contentful Paint)**：最大内容绘制时间，应 < 2.5 秒
- **FID (First Input Delay)**：首次输入延迟，应 < 100 毫秒
- **CLS (Cumulative Layout Shift)**：累积布局偏移，应 < 0.1

### 1.2 其他重要指标

- **FCP (First Contentful Paint)**：首次内容绘制
- **TTI (Time to Interactive)**：可交互时间
- **TBT (Total Blocking Time)**：总阻塞时间
- **Speed Index**：速度指数

### 1.3 性能监控工具

```javascript
// 使用 Performance API 监控性能
const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    console.log(entry.name, entry.duration);
  }
});

observer.observe({ entryTypes: ['navigation', 'resource', 'paint'] });

// 测量 LCP
new PerformanceObserver((entryList) => {
  const entries = entryList.getEntries();
  const lastEntry = entries[entries.length - 1];
  console.log('LCP:', lastEntry.renderTime || lastEntry.loadTime);
}).observe({ entryTypes: ['largest-contentful-paint'] });
```

```html
<!-- 原生懒加载 -->

<!-- 使用 Intersection Observer -->
<img data-src="image.jpg" class="lazy" alt="描述">

<script>
const images = document.querySelectorAll('img.lazy');
const imageObserver = new IntersectionObserver((entries, observer) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      img.classList.remove('lazy');
      observer.unobserve(img);
    }
  });
});

images.forEach(img => imageObserver.observe(img));
</script>
```

## 三、渲染性能优化

### 3.1 减少重排和重绘

#### 批量 DOM 操作

```javascript
// ❌ 不好：多次重排
const element = document.getElementById('myDiv');
element.style.width = '100px';
element.style.height = '100px';
element.style.margin = '10px';

// ✅ 好：使用 CSS 类
element.classList.add('new-style');

// ✅ 好：使用 requestAnimationFrame
requestAnimationFrame(() => {
  element.style.transform = 'translateX(100px)';
});

// ✅ 好：使用 DocumentFragment
const fragment = document.createDocumentFragment();
for (let i = 0; i < 1000; i++) {
  const div = document.createElement('div');
  fragment.appendChild(div);
}
container.appendChild(fragment);
```

#### 使用 transform 和 opacity

```css
/* ✅ 这些属性不会触发重排，只触发合成 */
.element {
  transform: translateX(100px);
  opacity: 0.5;
}

/* ❌ 这些属性会触发重排 */
.element {
  width: 100px;
  height: 100px;
  margin: 10px;
}
```

#### 使用 will-change

```css
/* 提示浏览器该元素会发生变化 */
.animated-element {
  will-change: transform, opacity;
}

/* 使用后记得移除 */
.element.animation-complete {
  will-change: auto;
}
```

### 3.3 防抖和节流

```javascript
// 防抖（Debounce）
function debounce(func, wait) {
  let timeout;
  return function executedFunction(...args) {
    const later = () => {
      clearTimeout(timeout);
      func(...args);
    };
    clearTimeout(timeout);
    timeout = setTimeout(later, wait);
  };
}

// 节流（Throttle）
function throttle(func, limit) {
  let inThrottle;
  return function(...args) {
    if (!inThrottle) {
      func.apply(this, args);
      inThrottle = true;
      setTimeout(() => inThrottle = false, limit);
    }
  };
}

// 使用示例
const handleScroll = throttle(() => {
  console.log('滚动事件');
}, 100);

window.addEventListener('scroll', handleScroll);
```

## 四、JavaScript 性能优化

### 4.1 避免内存泄漏

```javascript
// ❌ 内存泄漏示例
function createLeak() {
  const element = document.getElementById('myElement');
  element.addEventListener('click', () => {
    console.log('clicked');
  });
  // 元素被删除后，事件监听器仍然存在
}

// ✅ 正确做法
function createNoLeak() {
  const element = document.getElementById('myElement');
  const handler = () => {
    console.log('clicked');
  };
  element.addEventListener('click', handler);
  
  // 清理
  return () => {
    element.removeEventListener('click', handler);
  };
}

// React 中使用 useEffect 清理
useEffect(() => {
  const handler = () => console.log('clicked');
  element.addEventListener('click', handler);
  return () => element.removeEventListener('click', handler);
}, []);
```

### 4.2 优化循环和算法

```javascript
// ❌ 嵌套循环
for (let i = 0; i < array1.length; i++) {
  for (let j = 0; j < array2.length; j++) {
    // O(n²) 复杂度
  }
}

// ✅ 使用 Map 优化查找
const map = new Map(array2.map(item => [item.id, item]));
for (let i = 0; i < array1.length; i++) {
  const found = map.get(array1[i].id); // O(1) 查找
}

// ✅ 使用更高效的数组方法
const result = array1
  .filter(item => item.active)
  .map(item => item.value)
  .reduce((sum, val) => sum + val, 0);
```

### 6.3 缓存策略

```javascript
// Service Worker 缓存策略
self.addEventListener('fetch', (event) => {
  if (event.request.url.includes('/api/')) {
    // 网络优先
    event.respondWith(
      fetch(event.request)
        .then(response => {
          const clone = response.clone();
          caches.open('api-cache').then(cache => {
            cache.put(event.request, clone);
          });
          return response;
        })
        .catch(() => caches.match(event.request))
    );
  } else {
    // 缓存优先
    event.respondWith(
      caches.match(event.request)
        .then(response => response || fetch(event.request))
    );
  }
});
```

### 11.2 性能优化原则

1. **测量优先**：先测量，再优化
2. **关键路径优化**：优先优化影响首屏的关键资源
3. **渐进增强**：确保基础功能可用，再增强体验
4. **持续监控**：建立性能监控体系
5. **平衡取舍**：在性能和功能之间找到平衡

## 总结

前端性能优化是一个持续的过程，需要从多个维度综合考虑。关键是要：

1. **建立性能意识**：在开发过程中始终考虑性能
2. **使用工具测量**：用数据说话，不要猜测
3. **持续优化**：性能优化不是一次性的工作
4. **关注用户体验**：最终目标是提升用户体验

记住：**过早优化是万恶之源**，先确保功能正确，再优化性能。
